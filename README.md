# Cycle - Period Tracker\n\nCross-platform period tracking app built with React Native (Expo) and AsyncStorage.\n\n## Features\n- Log period dates, flow, and symptoms\n- Automatic average cycle length calculation\n- Predicted next period and fertile window\n- Calendar view with marked period days and fertile window\n\n## Tech\nReact Native, Expo, React Navigation, AsyncStorage, date-fns, react-native-calendars
